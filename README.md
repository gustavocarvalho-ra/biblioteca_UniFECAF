# 📚 Biblioteca Digital UniFECAF

Projeto acadêmico de desenvolvimento web que apresenta uma proposta de interface para a Biblioteca Digital UniFECAF, com foco na organização do conteúdo, na navegação intuitiva e na adaptação a diferentes tamanhos de tela.

## 📌 Sobre o projeto

A Biblioteca Digital UniFECAF foi desenvolvida como uma página web para apresentar conteúdos relacionados à leitura, à pesquisa e à aprendizagem acadêmica.

O projeto busca oferecer uma experiência visual organizada, permitindo que os visitantes naveguem pelas seções da página e conheçam os conteúdos ilustrativos apresentados.

## 🎯 Objetivos

- Desenvolver uma interface web organizada e intuitiva.
- Aplicar conceitos de HTML semântico e CSS.
- Criar uma página com layout responsivo.
- Facilitar a navegação entre as diferentes seções.
- Aplicar boas práticas de acessibilidade e organização do código.

## ✨ Seções do site

- **Início:** apresentação da biblioteca e acesso rápido ao acervo.
- **Sobre a biblioteca:** descrição da proposta e dos objetivos do espaço.
- **Nossos livros:** apresentação de seis cards ilustrativos de livros e conteúdos.
- **Unidades:** demonstração de espaços relacionados à leitura, pesquisa e aprendizagem.
- **Contato:** acesso ao site institucional da UniFECAF.
- **Rodapé:** identificação do projeto e link para retornar ao início da página.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo e utilização de elementos semânticos.
- **CSS3:** estilização, organização dos componentes visuais e responsividade.

## 📁 Estrutura do projeto

```text
biblioteca_UniFECAF/
```

*Observação: a estrutura acima representa a organização esperada dos arquivos utilizados pelo projeto. Os nomes e a localização das imagens devem corresponder aos arquivos presentes no repositório.*

## 🚀 Como executar o projeto

Como o projeto utiliza HTML e CSS, não é necessário instalar dependências ou executar um servidor de aplicação.

1. Clone o repositório:

   ```bash
   git clone https://github.com/gustavocarvalho-ra/biblioteca_UniFECAF.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd biblioteca_UniFECAF
   ```

3. Abra o arquivo `index.html` no navegador.

**Alternativa:** abra a pasta do projeto no Visual Studio Code e utilize a extensão Live Server para visualizar o site durante o desenvolvimento.

## 📱 Responsividade e acessibilidade

O projeto foi planejado para se adaptar a diferentes tamanhos de tela, incluindo computadores e dispositivos móveis.

Entre os recursos de acessibilidade presentes na estrutura estão:

- Definição do idioma da página como português do Brasil.
- Textos alternativos nas imagens.
- Identificação da navegação principal.
- Utilização de elementos semânticos do HTML.
- Links para facilitar o acesso às diferentes seções.

A experiência final deve ser validada em diferentes dispositivos e navegadores.

## 🖼️ Conteúdo demonstrativo

Os títulos, descrições dos livros e espaços apresentados possuem caráter ilustrativo. Eles representam uma proposta visual para a biblioteca e não devem ser interpretados como informações oficiais sobre o acervo ou as unidades da instituição.

Informações institucionais, endereços, serviços e disponibilidade de materiais devem ser confirmados antes de uma eventual utilização oficial.
